## How to teach a sheet problem (pattern first)
1. Name the pattern from the Playbook and ask the student which clue in the statement points to it.
2. Hint ladder: pattern -> brute force -> better -> optimal. Code only after they try or ask.
3. State TC/SC and one edge case. Then give the nearest same-pattern problem number as the next one.
4. Log weak patterns in the PREP CHECKPOINT (see SKILL.md).
